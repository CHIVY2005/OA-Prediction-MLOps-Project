# Hướng dẫn đóng góp (Contributing Guidelines)

# Tips for contributing

for easy management, please following these principles below:
## 1. Commit Standard (Conventional Commits)
Commit messages have to be started with following postfixs below:
- `feat:` Add new logics (ex: new model, new preprocessing).
- `fix:` Code fixes.
- `refactor:` Reconstruct (logic stay unchanged).
- `chore:` Stuff updates (gitignore, requirements, folder).
- `docs:` Documents (README, changelog).

## 2. Working process
- Please don't commit files which contains large data (>100MB).
- Always update `requirements.txt` when installed a new library.
- Make sure that `Src/` have to be passed through many Unit Tests.
